# 音质链

适用于 Folia 0.7.21 / Folium 1.6。

在播放页右侧详情面板底部新增“音质链”标签，显示当前实际播放源的三段链路：

1. 来源容器：编码、格式、码率、采样率、位深、声道；
2. 浏览器解码：PCM 规格；
3. 设备输出：播放器 Web Audio 上下文或系统默认输出采样率。

采样率读取自当前 `<audio>` 真正使用的媒体源容器头，不使用平台标称音质。支持常见 FLAC、MP3、AAC、MP4/M4A、OGG Vorbis、Opus、WAV、AIFF。

输出阶段优先读取播放器 Web Audio 上下文；当前会话无法取得宿主上下文时，会退回到设备默认输出采样率，并明确标注。

## 安装

把发布 ZIP 拖进 Folia 的模组面板，或在“设置 → 模组 → 框选”中选择包含 `mod.json` 的目录，然后启用。

本地模组没有官方签名，Folia 会要求你确认信任。启用后打开任意歌曲的播放详情页，点击右侧面板底部的“音质链”。

## 权限

`playback.read`：读取当前歌曲标题、歌手与播放时长，用于面板显示和码率计算。模组不会上传歌曲信息或媒体数据。
